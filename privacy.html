プライバシーポリシー

BudgetTracker (以下「このアプリ」) での、情報の取り扱いを説明します。このアプリは、開発者本人が使う個人用のアプリで、一般には配布していません。

取得する情報

このアプリは、利用者が Google アカウントでログインして許可した場合に、Gmail のメールを読み取る権限 (gmail.readonly) を使います。読み取るのは、クレジットカードの利用通知メールです。そこから、支払いの日時、金額、利用先を取り出します。

利用の目的

取り出した情報は、支払いを記録し、月の上限に対する残りを表示するためだけに使います。

保存と共有

取り出した情報と、Google へのログインの情報は、利用者の iPhone の中にだけ保存します。開発者のサーバーには送りません。第三者に提供、販売、共有することはありません。広告にも使いません。

Google の API から得た情報の利用は、Google API サービスのユーザーデータに関するポリシー (限定的な使用の要件を含む) に従います。

削除

アプリの設定の「接続を解除」で、Google へのログインの情報を消し、Google 側の許可も取り消します。アプリを削除すると、記録した支払いの情報は消えます。Google アカウントの設定からも、いつでも許可を取り消せます。

変更

このポリシーを変えたときは、このページを更新します。
